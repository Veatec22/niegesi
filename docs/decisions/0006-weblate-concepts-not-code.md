# Z Weblate bierzemy pomysły, nie kod

Status: przyjęte · Data: 2026-09-25 · Temat: [pracownia korekty](0003-editorial-workspace.md)

Weblate jest na GPL-3.0-or-later, a to repo na MIT. Przepisanie jego modułów na TypeScript
byłoby utworem zależnym i wymagałoby zmiany licencji. Czytamy kod Weblate tylko po to,
żeby zrozumieć rozwiązania (stany, bufor zmian, sprawdzenia, glosariusz), a implementację
piszemy od zera. Specyfikacja może wskazywać, skąd wziął się pomysł. Zestawienie pojęć jest
w [weblate-analysis.md](../weblate-analysis.md).
