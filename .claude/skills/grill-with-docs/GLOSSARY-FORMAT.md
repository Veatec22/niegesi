# Format słownika

Jeden plik: `docs/glossary.md`. Tworzysz go, gdy ustalisz pierwsze pojęcie.

```md
# Słownik Not Geese

<Jedno–dwa zdania: czego dotyczy.>

## <Grupa pojęć>

**Wpis**:
<Jedno–dwa zdania: czym to JEST, nie co robi.>
_Unikaj_: string, linijka
```

## Zasady

- **Wybieraj.** Gdy na jedno pojęcie jest kilka słów, wybierz najlepsze, resztę wpisz
  do _Unikaj_.
- **Krótko.** Jedno–dwa zdania na definicję.
- **Tylko pojęcia tego projektu.** Nie definiuj ogólnych pojęć programistycznych.
  Pytanie kontrolne: czy to pojęcie istnieje dlatego, że robimy spolszczenia gier?
- **Grupuj** pod nagłówkami, gdy naturalnie tworzą się skupiska
  (np. „Teksty gry”, „Korekta”, „Wymiana z repo”).
- Bez implementacji — nazwy tabel, funkcji i plików tu nie trafiają.
