# Somber Echoes PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość archiwum do głównego katalogu gry, czyli tam, gdzie leży `SomberEchoes.exe`. Jeśli była tu próbka 0.1, pozwól nadpisać plik paka.
3. Uruchom grę normalnie, bez żadnych opcji uruchamiania.
4. W opcjach wybierz język **Polski** (ostatnia pozycja listy) i włącz napisy. Wybór zostaje zapamiętany.

Spolszczenie nie podmienia żadnego pliku gry. Żeby je usunąć, wybierz w grze English, zamknij grę i skasuj `SomberEchoes/Content/Paks/pakchunk99-NieGesi-PL_P.pak`, `SomberEchoes/Binaries/Win64/dwmapi.dll` oraz folder `SomberEchoes/Binaries/Win64/ue4ss`. Przy innych modach UE4SS usuń tylko `ue4ss/Mods/NieGesiPL` i jego wpisy w `mods.txt` oraz `mods.json`.
