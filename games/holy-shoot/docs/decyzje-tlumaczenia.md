# Decyzje — próbka

- Run → wyprawa; souls → dusze; weak points → słabe punkty. Decyzje na podstawie tekstów ST_Tutorials z lokalnego Game.locres.
- Menu używa krótkich, standardowych poleceń: Wznów, Wyjdź, Zastosuj.
- „See it. Shoot it. Hurt it more.” → „Wypatrz. Wyceluj. Zaboli mocniej.” — zachowany krótki, zaczepny ton.
- Osobna kultura pl, bez nadpisania angielskich tekstów. W 0.1.1 wybór Polski jest dodawany do istniejącego selektora przez własne rozszerzenie Lua/UE4SS. Usunięto wymóg parametru uruchamiania. Duży panel ustawień gry nie trafia do paczki; modyfikujemy wyłącznie listę i mapę języków w pamięci.
- Zapis wyboru pozostaje po stronie oryginalnego mechanizmu ustawień. Przełączanie i restart wymagają potwierdzenia użytkownika przed pełnym tłumaczeniem.
- Sprawdzić w grze: ładowanie polskiego menu, ę/ź/ó/ł/ś/ć w ustawieniach, obcięcia suwaków głośności, powrót do angielskich tekstów poza próbką.
