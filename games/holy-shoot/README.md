# Holy Shoot PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość archiwum do katalogu Holy Shoot, czyli tam, gdzie jest folder `Windows`. W Steamie trafisz tam przez **Zarządzaj → Przeglądaj pliki lokalne**.
3. Uruchom grę normalnie, bez żadnych opcji uruchamiania.
4. Otwórz **Settings → Gameplay → Language** i wybierz **Polski** (ostatnia pozycja). Wybór zostaje zapamiętany.

Spolszczenie nie podmienia żadnego pliku gry. Żeby je usunąć, wybierz w grze English, zamknij grę i skasuj trzy pliki `Windows/PVD/Content/Paks/pakchunk99-NieGesiPL_P` (`.pak`, `.utoc`, `.ucas`), plik `Windows/PVD/Binaries/Win64/dwmapi.dll` oraz folder `Windows/PVD/Binaries/Win64/ue4ss`. Przy innych modach UE4SS usuń tylko `ue4ss/Mods/NieGesiPL` i jego wpisy w `mods.txt` oraz `mods.json`.
