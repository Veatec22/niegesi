# Turbo Overkill PL

## Instalacja

1. Zamknij grę.
2. Wypakuj całą zawartość paczki do katalogu z `Turbo Overkill.exe`.
3. Uruchom grę zwykłym skrótem. Pierwszy start potrwa dłużej i wymaga internetu — loader przygotowuje swoje biblioteki.
4. Otwórz wybór języka i kliknij **Polski** z biało-czerwoną flagą. Wybór jest zapamiętywany.

Żeby usunąć spolszczenie, zamknij grę i usuń folder `BepInEx/plugins/NieGesiTurboOverkill`. Oryginalne pliki gry pozostają bez zmian. Jeśli był to jedyny mod, możesz też usunąć dodany loader: foldery `BepInEx` i `dotnet` oraz pliki `winhttp.dll`, `doorstop_config.ini` i `.doorstop_version`.
